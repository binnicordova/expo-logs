# README image prompts

The images in this folder were designed in HTML/CSS using the real iOS Simulator screenshots (`screenshot-*.png`) and rendered to PNG.
To make alternative versions with Gemini (gemini.google.com, signed in), use these prompts and keep the same file names.

**hero.png** (wide banner, about 16:5)
> A wide 16:5 GitHub README hero banner for an open-source developer library called "expo-logs". Dark navy-to-indigo gradient background. On the left, large bold white text "expo-logs" with the subtitle "File logging for Expo apps · iOS · Android · Web". On the right, a modern smartphone at a slight angle whose screen shows neat lines of monospaced log text with small colored level tags (DEBUG gray, INFO blue, WARN amber, ERROR red), with three document icons labeled .log and one labeled .zip flowing out of it. Minimal flat vector style, crisp, lots of breathing room, no logos.

**steps.png** (about 8:3)
> A clean light-themed infographic with three numbered cards connected by arrows: "1 Install" (terminal icon), "2 Configure once" (code brackets icon), "3 Share the logs" (share icon with a phone). Indigo and violet accents, rounded cards, soft shadows, flat vector, minimal text, developer-docs aesthetic.

**use-cases.png** (about 20:9)
> A dark-themed grid of six rounded tiles with simple line icons illustrating mobile app logging use cases: customer support bug report with attached logs, QA beta tester exporting a zip, offline field worker with a phone, crash warning triangle, over-the-air update arrow, web browser globe. Indigo/violet glow, flat vector, minimal, no text.
